# GCNet (Global Context Block)

## 🔍 Overview | 概述

**English**

GCNet introduces a **Global Context (GC) block** to capture long-range dependencies with low cost.
Instead of building an NxN attention matrix (like Non-local), it:

1) **Pools** spatial information into a global context vector `(B, C, 1, 1)`
   - `avg` pooling or `att` (attention) pooling
2) Uses a small **bottleneck transform** to model channel relationships
3) **Fuses** the context back via:
   - `channel_add`: residual add
   - `channel_mul`: sigmoid gate multiply

**中文**

GCNet 的 GC Block 用低成本建模长距离依赖。  
它不构造 Non-local 的 NxN 注意力矩阵，而是：

1) 把空间信息池化成全局上下文 `(B, C, 1, 1)`（avg 或 attention pooling）
2) 用一个小瓶颈网络建模通道关系
3) 再通过加法/乘法把上下文融合回原特征

---

## ⚙️ Input / Output | 输入输出

- Input:  \(X \in \mathbb{R}^{B \times C \times H \times W}\)
- Output: \(Y \in \mathbb{R}^{B \times C \times H \times W}\)

---

## 🧠 Step 1: Spatial Pooling | 第一步：空间池化拿 Context

### Option A: Average pooling | 平均池化

\[
context = GAP(X) \in \mathbb{R}^{B \times C \times 1 \times 1}
\]

### Option B: Attention pooling | 注意力池化（推荐）

**English**

Compute a spatial mask (1-channel) and softmax over all spatial positions:

\[
mask = Conv_{1\times1}(X) \in \mathbb{R}^{B \times 1 \times H \times W}
\]
\[
\alpha = softmax(mask) \in \mathbb{R}^{B \times 1 \times (H\cdot W)}
\]

Then do weighted sum over spatial tokens:

\[
context = \sum_{i=1}^{HW} \alpha_i \cdot X_i
\Rightarrow context \in \mathbb{R}^{B \times C \times 1 \times 1}
\]

**中文**

用 1×1 卷积得到空间权重，再对 HW 做 softmax（所有位置权重和=1）：

\[
mask = Conv_{1\times1}(X)
\]
\[
\alpha = softmax(mask)
\]

用它对全图做加权求和得到全局上下文：

\[
context = \sum \alpha_i \cdot X_i
\]

---

## 🧠 Step 2: Bottleneck Transform | 第二步：小网络建模通道关系

Transform network:

\[
T(context) = Conv1\times1(C \rightarrow C\cdot r)
\rightarrow Norm \rightarrow ReLU
\rightarrow Conv1\times1(C\cdot r \rightarrow C)
\]

- `ratio=r` controls the bottleneck size (e.g. 0.25)

---

## 🧠 Step 3: Fusion | 第三步：融合回原特征

Two fusion types (can be used together):

### ✅ channel_mul | 乘法门控

\[
gate = \sigma(T(context)) \in \mathbb{R}^{B \times C \times 1 \times 1}
\]
\[
Y = X \otimes gate
\]

### ✅ channel_add | 加法偏置（残差）

\[
bias = T(context) \in \mathbb{R}^{B \times C \times 1 \times 1}
\]
\[
Y = X + bias
\]

---

## 🧾 Where is the Attention? | 注意力在哪里？

- If `pooling_type='att'`, the attention is the **spatial softmax mask**:
  - shape: `(B, 1, H*W)`
  - generated by: `conv_mask + softmax`
- The final gating (if `channel_mul`) is:
  - shape: `(B, C, 1, 1)`
  - `sigmoid(channel_mul_conv(context))`

---

## 🔑 Key Parameters | 关键参数

| Parameter | English | 中文 |
|----------|---------|------|
| inplanes | input channels C | 输入通道数 |
| ratio | bottleneck ratio r | 瓶颈比例（越小越省） |
| pooling_type | 'avg' or 'att' | 平均池化 or 注意力池化 |
| fusion_types | add/mul or both | 加法/乘法融合 |

---

## ✅ Pros | 优点

**English**
- Efficient global context modeling
- Much cheaper than Non-local
- Plug-and-play for CNN backbones

**中文**
- 用很小的开销获取全局上下文
- 比 Non-local 省显存、省计算
- 易插拔，适合 backbone 各 stage

---

## ⚠️ Cons | 局限

**English**
- Produces a single global context per channel (not full pairwise spatial attention)
- Attention pooling adds extra conv + softmax cost (still small)

**中文**
- 每个通道只有一个全局上下文，不是完整的空间两两注意力
- attention pooling 有 softmax，但总体仍很轻

---

## 🧪 Minimal Example | 最小示例

```python
import torch
from attention.gcnet import ContextBlock

x = torch.randn(2, 128, 32, 32)
gc = ContextBlock(inplanes=128, ratio=0.25, pooling_type='att', fusion_types=('channel_add','channel_mul'))
y = gc(x)
print(y.shape)  # (2, 128, 32, 32)
